# Planificateur d'études

Application mobile (PWA) pour organiser ses études : tâches, examens, calendrier, notes et documents.

## Structure

- `index.html` : page principale
- `css/` : styles
- `js/` : scripts
- `icons/` : icônes de l'application
- `manifest.json` : fiche d'identité de la PWA (nom, couleurs, icônes)
- `sw.js` : Service Worker (fonctionnement hors ligne)
